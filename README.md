# Employee Payroll App

Employee Payroll App is a Java-based payroll management system designed to demonstrate real-world Object-Oriented Programming (OOP) concepts through enterprise payroll operations. The application handles employee registration, authentication, payslip generation, dashboard management, and validation while showcasing principles such as encapsulation, inheritance, polymorphism, composition, interfaces, and exception handling. 

---

## Features

* Employee registration and authentication
* Secure login and session handling
* Monthly payslip generation
* Payslip print and download support
* Personalized payroll dashboard
* Input validation using RegEx
* Exception handling and validation framework
